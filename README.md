# 批量图片裁剪工具 v1.0

批量加载图片，按目标宽高比可视化裁剪，零压缩无损输出。

## 功能特性

- ✅ **批量导入** — 多文件 + 文件夹导入（jpg/png/bmp/webp/tiff/gif）
- ✅ **可视化裁剪** — 裁剪框内原图清晰，框外半透明遮罩预览
- ✅ **拖拽/键盘微调** — 鼠标拖拽移动裁剪框，方向键精确调整
- ✅ **滚轮缩放预览** — 鼠标滚轮放大缩小预览视图
- ✅ **单图独立变换** — 每张图可单独设置水平/垂直翻转、旋转
- ✅ **批量复制变换** — 一键将当前图的变换设置应用到所有图片
- ✅ **零压缩输出** — 直接截取原图像素，不缩放不重采样
- ✅ **绿色免安装** — 单文件 exe，无需管理员权限

## 使用方法

### 直接运行 EXE

从 [Releases](../../releases) 下载 `BatchImageCrop.exe`，双击运行。

### 从源码运行

```bash
pip install -r requirements.txt
python BatchImageCrop.py
```

### 操作流程

1. 点击「添加图片」或「添加目录」导入图片
2. 输入裁剪比例（如 `10 : 7`，仅取比例，单位随意）
3. 在预览图上**拖拽裁剪框**调整位置
4. 如需变换，在右侧面板设置翻转/旋转（每张可单独设）
5. 选择输出目录，点击「批量裁剪导出」

### 快捷键

| 按键 | 功能 |
|------|------|
| `← → ↑ ↓` | 移动裁剪框（5像素步长） |
| `Shift + 方向键` | 移动裁剪框（1像素精度） |
| `鼠标滚轮` | 缩放预览视图 |

## 技术栈

- Python 3.11+
- tkinter + ttkbootstrap (flatly 主题)
- Pillow (图片处理)
- PyInstaller (打包)
